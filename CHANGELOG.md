# Changelog - Kogutopedia

## v0.0.1 (Alpha)
- Initial project setup with Flutter
- Clean Architecture foundation: data, domain, presentation layers
- Isar local NoSQL database integration
- Basic entry management (CRUD operations)
- Image picker and cropper for media attachments
- EXIF metadata reading for automatic date capture
- Multi-character support (Tomek, Marek, Kasia + custom names)
- Streak counter system (days with Tomek activity - never resets)
- Glassmorphism UI theme (dark navy, cyan accents)
- Responsive layout (mobile, tablet, desktop)
- Daily challenge system with local achievements
- Dashboard with statistics and gallery
- GitHub Actions CI/CD pipeline
- Platform support: Android, Linux, Windows
